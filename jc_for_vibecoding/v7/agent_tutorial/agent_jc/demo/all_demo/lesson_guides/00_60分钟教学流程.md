# 60 分钟教学流程

## 课程主线

本教学包不是讲“如何写一个神奇 prompt”，而是讲 **如何用 OpenCode 把一个场景沉淀成 Agent 应用**。

```text
用户一句话需求
  -> OpenCode command 作为入口
  -> Skill 选择任务流程
  -> AGENTS.md 提供长期规则
  -> references 提供历史文档和规范
  -> tools/scripts 提供受控动作空间
  -> validation scripts 提供观察和纠偏
  -> manifest/report 提供交接和审计
```

## 时间安排

| 时间 | 内容 | 演示文件 |
|---:|---|---|
| 0-5 min | Agent = 带状态的决策循环；context = 分层系统 | `README.md` |
| 5-8 min | OpenCode 项目骨架：AGENTS.md / Skill / Command / Tool / Permission | 根目录和 Demo 00 |
| 8-20 min | Demo 00：规则驱动 dashboard，演示从一句话到稳定 HTML 产物 | `00_rule_dashboard_agent` |
| 20-33 min | Demo 01：文档 + 样例 + golden test 驱动迁移开发 | `01_doc_spec_portability` |
| 33-48 min | Demo 02：PDF/论文信息抽取、Skill 串联、复现项目生成 | `02_pdf_reproduction_agent` |
| 48-56 min | Demo 03：权限约束、受控脚本和 Data Service，让 Agent 只能在 sandbox 动作 | `03_permission_sandbox_agent` |
| 56-60 min | Takeaway：动作空间、取证验证、分层 context、运行时组合 | `lesson_guides/context分层速查表.md` |

## 每个 demo 的讲解模板

1. 业务一句话是什么。
2. 如果只靠 prompt，会不稳定在哪里。
3. 我们把 context 拆成哪些层。
4. Agent 可以做哪些动作，不能做哪些动作。
5. 哪个脚本负责执行，哪个脚本负责验证。
6. 如果涉及数据，原始数据在哪里被隔离，聚合字段在哪里被白名单化。
7. 哪些结果能自动验证，哪些必须人工 review。
