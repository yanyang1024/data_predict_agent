# Frontend Style Spec

## 风格目标

迁移后的 Flask Web App 应保持和原 Gradio demo 一致的“数据分析工作台”风格：安静、紧凑、适合反复上传和查看结果，而不是营销页。

## 布局

- 首屏直接是 CSV 上传和结果工作台，不做 landing page。
- 页面最大宽度 1120px，居中显示。
- 顶部使用产品名 `CSV Insight Workbench` 和一句短说明。
- 上传区、统计区、图表区和表格区分区清晰。
- 卡片圆角不超过 8px。

## 视觉规范

- 主背景：`#f6f8fb`
- 文本主色：`#1f2937`
- 强调色：`#0f766e`
- 辅助强调：`#b45309`
- 成功色：`#137333`
- 边框色：`#d8dee9`

## 组件要求

- 上传按钮应有明确动作文本。
- 统计结果用小型 metric cards 展示。
- 图表应直接显示在页面内，不只给文件链接。
- 表格需要有表头、斑马纹和紧凑 padding。
- 错误信息应显示在上传区附近。
