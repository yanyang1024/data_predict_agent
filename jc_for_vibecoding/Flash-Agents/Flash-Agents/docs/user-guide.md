# 用户使用教程

本文面向 Flash-Agents 的应用用户，说明如何登录、选择 Agent、发起任务、查看结果、使用工作区文件、上传技能，以及管理员如何查看后台数据。

## 你可以用它做什么

Flash-Agents 提供多个专业 Agent。每个 Agent 都会在隔离工作区内执行任务，并通过聊天界面实时返回进度、推理说明、todo、工具调用和文件结果。

当前内置 Agent：

| Agent | 适合任务 |
| --- | --- |
| 代码工程师 | 代码生成、重构、调试、仓库分析。 |
| PPT 助手 | 生成演示文稿大纲、页面内容、备注和素材清单。 |
| 流程图助手 | 生成 Mermaid / PlantUML 流程图和架构图。 |
| 数据分析师 | CSV/Excel 数据检查、统计分析、可视化建议。 |
| 文档工程师 | 需求文档、设计文档、接口文档、知识库文章。 |
| QA 测试专家 | 测试用例、缺陷复现、验收标准。 |
| 运维助手 | 部署、日志分析、监控、故障排查。 |
| 会议纪要助手 | 会议记录整理、行动项跟踪。 |
| 安全审查助手 | 权限、依赖、配置、隔离和审计检查。 |

你看到的 Agent 由所在域决定，例如 `RD`、`MEC`、`IT`。

## 登录

### 开发环境登录

1. 打开平台地址。
2. 输入邮箱、域、员工序号。
3. 点击“开发登录”。

员工序号会影响后端为你分配的 OpenCode 端口。普通用户不需要关心端口，只需使用管理员提供的账号信息。

### SSO 登录

1. 点击“SSO 登录”。
2. 跳转到企业统一认证页面。
3. 完成认证后会回到平台。

如果 SSO 回调失败，请回到登录页重新发起登录，或联系管理员检查账号域和权限。

## 开始一次对话

1. 进入“对话”页面。
2. 在顶部选择合适的 Agent。
3. 在底部输入任务。
4. 点击“发送”。

首次发送消息时，平台才会为当前会话创建 OpenCode session 和工作区。这可以减少空闲资源占用。

示例任务：

```text
请用流程图说明这个系统的登录链路，并输出 Mermaid。
```

```text
请帮我写一个接口测试用例清单，覆盖正常、异常、权限和并发场景。
```

```text
请根据工作区中的 CSV 做字段检查，列出缺失值、异常值和建议图表。
```

## 查看流式结果

发送任务后，界面会逐步出现以下内容：

- 助手回复：最终面向你的文本结果。
- 推理块：Agent 的阶段性分析。
- Todo：任务拆解和执行状态。
- 工具卡片：Agent 调用工具或访问工作区的记录。
- 问题卡片：Agent 需要你确认时出现。

如果长时间无响应，页面可能提示“流式响应超过 45 秒没有事件”。你可以等待、点击“中止”，或新建会话重试。

## 回答 Agent 的问题

如果 Agent 需要确认，会出现“Agent 需要确认”卡片。带选项的问题可以直接点击选项按钮，平台会把答案发送给执行引擎。

适合确认的问题包括：

- 是否覆盖已有文件。
- 选择哪个方案。
- 是否继续执行高风险操作。
- 从多个数据口径中选择一个。

如果问题没有选项，可以在输入框中用自然语言补充回答。

## 中止任务

任务运行时，页面右上方会出现“中止”按钮。

点击后平台会请求执行引擎停止当前任务，并拒绝挂起的问题。中止后你可以继续在同一会话发送新消息，也可以新建会话。

## 使用会话列表

左侧是你的历史会话。

- 点击会话可以恢复历史消息。
- 新消息会继续追加到当前会话。
- 点击“新建会话”会清空当前界面，下一次发送消息时创建新会话。

如果刷新页面后提示 OpenCode 内存状态丢失，说明执行引擎中的临时状态已经不存在。历史消息仍可查看，但挂起的 todo 或问题可能无法继续。

## 工作区文件

每个会话都有独立工作区。右侧“工作区文件”会显示当前会话产生的文件。

可以做的事：

- 查看文件列表。
- 打开文本文件。
- 预览 PDF 首页。
- 打开 PPT/PPTX 原文件。

注意：

- 首条消息发送前，工作区还没有绑定。
- 你只能访问自己的会话工作区。
- 如果文件列表为空，说明 Agent 尚未生成文件，或任务没有写入工作区。

## Markdown、公式和图表

助手消息支持：

- Markdown。
- 表格。
- 代码块。
- 数学公式。
- Mermaid 图。

如果需要流程图，可以明确要求：

```text
请用 mermaid 代码块输出流程图。
```

## 上传和查看技能

技能用于扩展 Agent 能力。进入“技能”页面可以查看当前域和当前用户可用技能。

### 上传技能

1. 准备 ZIP 技能包。
2. ZIP 根目录包含 `SKILL.md`，或包含 manifest 并声明 entrypoint。
3. 打开“技能”页面。
4. 选择 ZIP 文件。
5. 点击“上传”。

上传后，技能会存入你的域和你的个人技能目录。系统技能由管理员统一维护。

### 技能上传失败怎么办

常见原因：

- 不是 `.zip` 文件。
- ZIP 中包含不安全路径，例如 `../`。
- ZIP 中包含 symlink。
- 没有 `SKILL.md` 或 manifest entrypoint。

请重新打包后再上传。

## 管理后台

只有管理员可以看到“管理”入口。

管理后台包含：

- 用户数量。
- 会话数量。
- 当前运行实例数量。
- 用户列表。
- 审计 CSV 导出。

审计 CSV 适合用于安全检查、问题追踪和运营统计。

## 使用建议

### 选择合适 Agent

- 代码、仓库、脚本问题：选“代码工程师”。
- 流程、架构图：选“流程图助手”。
- 汇报材料：选“PPT 助手”。
- 文档和制度：选“文档工程师”。
- 测试和验收：选“QA 测试专家”。
- 部署和日志：选“运维助手”。
- 权限和安全：选“安全审查助手”。

### 写清楚任务

建议包含：

- 背景。
- 输入材料在哪里。
- 期望输出格式。
- 约束条件。
- 是否允许修改文件。

示例：

```text
请阅读工作区中的接口文档，输出一份测试用例表格。
要求包含用例标题、前置条件、步骤、预期结果、优先级。
不要修改文件，只在聊天中输出。
```

### 对文件生成任务说明路径

示例：

```text
请在工作区生成 docs/api-test-plan.md，内容是接口测试计划。
```

## 常见问题

### 为什么我看不到某个 Agent

可能是该 Agent 不属于你的域。请联系管理员确认你的域和 Agent 配置。

### 为什么会话刷新后没有继续执行

聊天历史会保存，但执行引擎中的临时运行状态不一定保留。如果会话已经空闲回收或引擎重启，挂起任务需要重新发起。

### 为什么文件打不开

可能原因：

- 文件不存在。
- 文件在其他会话工作区。
- 文件是二进制格式，当前只支持有限预览。
- 文件编码不常见。

### 为什么任务结果像演示内容

开发环境可能启用了 OpenCode mock。当真实执行引擎不可达时，平台会返回 mock 流。生产环境应由管理员关闭 mock。

### 如何退出登录

点击右上角“退出”。退出后本地 JWT 会被清除。
