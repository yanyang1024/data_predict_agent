# 1 小时教学规划

## 目标

让学员通过四个小项目理解：Agent 应用不是一次 prompt，而是稳定上下文 + 受控执行 + 验证 + 人工确认。

## 时间规划

| 时间 | 环节 | 讲解重点 | 演示动作 |
|---|---|---|---|
| 00-08 | Demo00 文档生成 | OpenCode 辅助项目工作流；模板、脚本、Skill 如何协同 | 一句话生成 PPT、Excel、Gantt |
| 08-23 | Demo01 Doc Spec | 历史文档 + 样例 + 平台契约如何形成可移植实现 | 抽取 contract，生成 JS，跑测试 |
| 23-40 | Demo02 富文本抽取 | PDF/富文本信息抽取规则；Skill 串联执行；人工介入点 | 抽取 pattern，适配环境包，语法验证 |
| 40-55 | Demo03 权限约束 | 重要数据和配置不直接交给 Agent；用脚本/API 收窄执行空间 | 受控查询、非法参数失败、审计日志 |
| 55-60 | 总结 | Context engineering checklist | 回顾 Skill 目录结构 |
