# Agent 应用上下文构成图

| 组件 | 解决的问题 | 放什么 | 不应该放什么 |
|---|---|---|---|
| AGENTS.md | 项目长期规则 | 目录结构、测试命令、禁止动作、安全边界 | 大段业务文档全文 |
| Command | 高频入口 | `/course-update`、`/port-spec` 等用户常用任务模板 | 复杂业务逻辑 |
| Skill | 某类任务怎么做 | 流程、工具顺序、输入输出、Stop Rules、报告格式 | 大量代码或长文档全文 |
| references | 业务知识 | schema、术语表、检查表、模板说明、抽取规则 | 需要执行的逻辑 |
| scripts / API | 可执行能力 | 查询、转换、验证、渲染、报告生成 | 需要模型自由发挥的判断 |
| tool | Agent 可调用动作 | 对脚本/API 的结构化封装 | 无权限边界的万能 shell |
| validator | 自动验收 | 文件存在、语法、schema、参数边界、样例测试 | 业务 signoff |
| Human review | 逻辑验收 | 方案确认、歧义裁决、最终结果确认 | 可自动化的格式检查 |
