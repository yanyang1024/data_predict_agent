# Source Notes for Instructor

These demo scenarios are synthetic and should not quote proprietary manuals,
paid standards, or production data.

Useful public references to mention during lecture:

- Cline Plan and Act: Plan mode is for understanding and strategy; Act mode implements after a plan.
- Cline Rules and Skills: Rules are persistent project instructions; Skills are on-demand task workflows.
- OpenCode Skills: project-local skills live under `.opencode/skills/<name>/SKILL.md`.
- OpenCode Custom Tools: TypeScript/JavaScript tool wrappers can call Python or shell scripts.
- OpenCode Permissions: allow/ask/deny gates can be used for edit, bash, skill, webfetch, and other actions.
- Accellera UVM: UVM provides standardized reusable verification methodology; sequences generate stimulus.
- JEDEC: JEDEC publishes microelectronics standards, including memory standards. For classroom demos, use synthetic excerpts.
- ATE vendor documentation: public ATE pages discuss test program development, vector/pattern handling, and platform compatibility, but real manuals are proprietary.
