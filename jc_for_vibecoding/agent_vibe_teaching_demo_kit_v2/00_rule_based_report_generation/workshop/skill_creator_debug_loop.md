# Skill creator + human debugging loop

Use this as the first practical teaching story.

1. Human gives three concrete examples: input status, expected report, forbidden claim.
2. Agent drafts the skill description and workflow.
3. Human checks whether the skill triggers for the right request.
4. Agent runs the generator and validator.
5. Human reviews output quality and flags one failure.
6. Agent tightens SKILL.md, report rules, or script validation.
7. Repeat until the workflow is stable.

The stable application is not created by one perfect prompt. It is created by skill instructions, deterministic scripts, validation reports, and human review.
